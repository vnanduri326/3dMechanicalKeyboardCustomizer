# 3D Mechanical Keyboard Customizer ⌨️
Looking to build your first mechanical keyboard? Look no longer! Customizer your own keyboard with 3D Mechanical Keyboard Customizer 

### How it Works:
* Gives user the option to filter preferences for keyboard parts
* interactive 3D keyboard parts

### Specifications:
* Frontend: Typescript / 3.js / React
* Backend: Python / Filter API
* Libraries: Playwright / Pydantic / PostgreSQL
